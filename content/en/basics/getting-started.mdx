Mik Casual is a non-profit creative Minecraft server focused on building and relaxed play.

## Before You Join

<Definitions>
<Definition title="Java Edition">

The server runs `26.3` and supports stable releases from `1.21.10` through `26.3`.

</Definition>
<Definition title="Bedrock Edition">

The latest few stable releases are supported. Complete [Geyser account linking](https://link.geysermc.org/start) before joining.

</Definition>
</Definitions>

## Joining the Server

<Steps>
<Step title="Join the Community">

[Server Rules](?section=rules) · [Join through QQ or Matrix](/en/join)

- **QQ:** get a join code on the join page, complete verification, and enter the group.
- **Matrix:** use the join page to join the community Space, then join a chat room with the bot.

</Step>
<Step title="Connect to Get a Linking Command">

Java Edition address:

```text
mcmik.top
```

Ask in the community for the Bedrock address and port.

If your account is not linked, the disconnect screen provides a complete linking command for each available platform. Choose a platform and copy its command. The six-digit code is valid for 5 minutes.

</Step>
<Step title="Link Your Account and Reconnect">

- **QQ:** mention the bot in a connected group and send `/bind <code>` from the disconnect screen.
- **Matrix:** send `!bind <code>` from the disconnect screen in a connected chat room.

After either platform is linked, reconnect to the server. The six-digit QQ join code is separate from your game account linking code.

</Step>
</Steps>

Keep at least one valid platform link and remain in a connected community to retain access. For Matrix, membership of the community Space provides access; chat rooms are where you send commands.

## Your First Login

You first arrive in the main city.

<Definitions>
<Definition title="Main Menu">

Sneak and press Swap Item With Offhand (default `Shift + F`), or use `/menu`.

</Definition>
<Definition title="/spawn" code>

Return to the main city.

</Definition>
<Definition title="/home" code>

View saved homes.

</Definition>
</Definitions>

<Callout title="Newcomer Permissions">

Newcomers can build and chat. Large-scale editing and other high-impact actions require Member status. See [Newcomers and Members](?section=rules#newcomers-and-members) for promotion requirements.

</Callout>

Use [web chat](/en/chat) to keep chatting outside the game. See [Chat system](?section=chat) for channels, private messages, and platform bridging

## Start Creating

<Steps>
<Step title="Choose a Site">

[World map](/en/map) · [Plot and building rules](?section=rules#plots-and-building)

</Step>
<Step title="Save Your Location">

```mcfunction
/sethome base
```

Save the current location as `base`; return with `/home base`.

</Step>
</Steps>

Members can register plots from the main menu.

<Callout kind="warning" title="World Border">

The overworld border is `9126` blocks in diameter. Players, builds, and entities must remain inside it.

</Callout>

## Recommended Mods

Optional Java Edition mods.

<Definitions>
<Definition title="Voice and Music">

[Plasmo Voice](https://modrinth.com/plugin/plasmo-voice): voice chat and server audio playback.

</Definition>

## If Something Does Not Work

<Details title="Asked to Link Your Account, or Still Unable to Enter After Linking?">

Follow the disconnect screen's command in a connected QQ group or Matrix room, then reconnect. Reconnect to get a new code if yours expires. If membership cannot be verified, try again later or contact staff. If access still fails, provide your Java username and the full error message. Bedrock players should also provide the linked Java account.

</Details>

<Details title="What Happens If I Leave a QQ Group or the Matrix Space?">

A link remains while that account is still in another connected community on the same platform. Once the server confirms the account has left all connected communities on that platform, that link is removed. Other valid links remain. If no valid links remain, rejoin a community and link your account again before reconnecting.

</Details>

<Details title="Version Mismatch, or Unable to Connect After Bedrock Linking?">

Check the game version. For Bedrock, also check Geyser account linking, your community platform link, the address, and the port. Include your game version and full error message when asking for help.

</Details>

<Details title="You Can Join, but a Tool or Command Is Unavailable?">

Some features require Member status or extra permissions. Check your role in the main menu; see [Common Commands](?section=commands) for syntax.

</Details>
