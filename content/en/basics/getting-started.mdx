Mik is a casual creative server focused on building and conversation.

## Before You Join

<Definitions>
<Definition title="Java Edition">

The server runs `26.3` and supports stable releases from `1.21.10` through `26.3`.

</Definition>
<Definition title="Bedrock Edition">

The latest few stable releases are supported. Complete [Geyser account linking](https://link.geysermc.org/start) before joining.

</Definition>
</Definitions>

## Joining the Server

<Steps>
<Step title="Apply for the whitelist">

[Server Rules](?section=rules) · [Apply](/en/join)

- **QQ group:** join the QQ group and apply according to its notice. Results are posted in the group.
- **Application form:** submit the form with your Java username, email, and a short introduction. Results arrive by email.

</Step>
<Step title="Connect to the server">

Java Edition address:

```text
mcmik.top
```

The application channel provides the Bedrock address and port.

</Step>
</Steps>

## Your First Login

You first arrive in the main city.

<Definitions>
<Definition title="Main menu">

Sneak and press Swap Item With Offhand (default `Shift + F`), or use `/menu`.

</Definition>
<Definition title="/spawn" code>

Return to the main city.

</Definition>
<Definition title="/home" code>

View saved homes.

</Definition>
</Definitions>

<Callout title="Newcomer permissions">

Newcomers can build and chat. Large-scale editing and other high-impact actions require Member status. See [Newcomers and Members](?section=rules#newcomers-and-members) for promotion requirements.

</Callout>

Use [web chat](/en/chat) to keep chatting outside the game. See [Chat system](?section=chat) for channels, private messages, and platform bridging

## Start Creating

<Steps>
<Step title="Choose a site">

[World map](/en/map) · [Plot and building rules](?section=rules#plots-and-building)

</Step>
<Step title="Save your location">

```mcfunction
/sethome base
```

Save the current location as `base`; return with `/home base`.

</Step>
</Steps>

Members can register plots from the main menu.

<Callout kind="warning" title="World border">

The overworld border is `9126` blocks in diameter. Players, builds, and entities must remain inside it.

</Callout>

## Recommended Mods

Optional Java Edition mods.

<Definitions>
<Definition title="Voice and music">

[Plasmo Voice](https://modrinth.com/plugin/plasmo-voice): voice chat and server audio playback.

</Definition>
<Definition title="Maps and navigation">

[Xaero's World Map](https://modrinth.com/mod/xaeros-world-map): explored-area map. [Xaero's Minimap](https://modrinth.com/mod/xaeros-minimap): minimap.

</Definition>
<Definition title="Building tools">

[Axiom](https://modrinth.com/mod/axiom): building and terrain editing. WorldEdit is provided on the server and needs no client mod.

</Definition>
</Definitions>

<Details title="Optimization modpacks and other client tools">

- [Fabulously Optimized](https://modrinth.com/modpack/fabulously-optimized) / [Rapid Optimization](https://modrinth.com/modpack/rapid_optimization): optimization modpacks.
- [ImageFrame Client](https://modrinth.com/mod/imageframeclient): higher-resolution, full-color map images, limited by server support and image type.
- [Vivecraft](https://modrinth.com/mod/vivecraft): VR play.
- [Hey Wiki](https://modrinth.com/mod/hey-wiki): in-game Wiki lookup.
- [Distant Horizons](https://modrinth.com/mod/distanthorizons) / [voxy](https://modrinth.com/mod/voxy): distant terrain rendering.

</Details>

## If Something Does Not Work

<Details title="Not whitelisted, or still unable to join after applying?">

Check QQ or email for the approval result. If access still fails, send staff your Java username and the full error message. Bedrock players should also provide the linked Java account.

</Details>

<Details title="Version mismatch, or unable to connect after Bedrock linking?">

Check the game version. For Bedrock, also check account linking, whitelist approval, address, and port. Include your game version and full error message when asking for help.

</Details>

<Details title="You can join, but a tool or command is unavailable?">

Some features require Member status or extra permissions. Check your role in the main menu; see [Common Commands](?section=commands) for syntax.

</Details>
