## Axiom

Axiom is a client mod for building and terrain editing.

- [Download](https://modrinth.com/mod/axiom)
- [Server guide](https://hi-ysumc.feishu.cn/wiki/QDJBwtCBEi5eLakfWCvcRtErnvb)

### Common controls

| Action | Function |
| --- | --- |
| Hold `Left Alt` in Creative mode | Open the Builder menu |
| Press `Right Shift` | Enter Editor mode for terrain editing, brushes, and other tools |
| Use the No-Clip toggle in the Builder menu | Enable or disable moving through blocks |
