## 适用与联系

Encinet 团队负责 Mik Casual 游戏服务器、官网及团队运营的 QQ、Matrix 社区功能中的个人信息处理。第三方平台独立处理的数据适用其各自的隐私政策。

如有隐私问题或数据请求，请通过[社区](/zh-CN/join)私信维护者（Custodian）。涉及玩家数据时，请提供玩家名或 UUID。

## 数据与用途

| 范围 | 处理的数据与用途 |
| --- | --- |
| Minecraft 联机与存档 | IP 及连接信息用于联机和身份核验；UUID、玩家名及皮肤用于身份识别和显示；位置、物品栏、末影箱、进度及统计用于保存角色状态；建筑、地形、容器、实体、告示牌和书本等随世界保存 |
| 服务器功能 | QQ／Matrix 账号标识、成员资格及绑定关系用于入服核验；权限、地段、设置及游玩记录用于访问控制、建筑保护、偏好保存和晋升；治理、操作记录及举报证据用于投票、规则执行和纠纷处理 |
| 官网功能 | IP、请求、浏览器及错误记录用于网站运行和安全防护；临时验证码、Passkey 公钥及会话信息用于身份认证；投稿者身份、作品说明、坐标、图片及审核记录用于建筑收录 |

数据来自你的连接、游戏和网页操作、提交内容，以及游戏认证和社区平台。入服须保留至少一条有效的 QQ 或 Matrix 绑定。

我们不出售个人信息。提供服务所必需的数据基于履行服务约定处理；依法必须处理的数据以法定义务为依据。适用法律允许时，安全防护、违规处置及申诉所需的数据可基于正当利益处理。依法需要同意的处理活动将事先征求同意。

## 通信与公开范围

- **公共聊天**在游戏、网页和 Matrix 间同步，并写入控制台日志。QQ 一群的消息同步至上述公共频道；向 QQ 发送的消息须以半角 `#` 开头并通过审核，详见[互通规则](?section=chat#平台互通)。
- **私聊与管理频道**分别向通信双方及具有相应权限的人员投递，不转发至 QQ 群或 Matrix 房间。
- **语音聊天**通过 Plasmo Voice 传输至收听者。
- **公开信息**包括玩家名、UUID、皮肤、在线状态及本次入服时间，无需登录即可通过官网或公开接口查询。建筑信息、署名及公开的处分和治理结果依照[服务器规则](?section=rules)展示。

网页聊天采用浏览器与游戏服务端之间的应用层加密，消息正文在进入 Cloudflare 代理前已加密。Cloudflare 可以获取 IP、连接时间等网络信息，但不持有聊天正文的应用层解密密钥。

游戏服务端负责解密和处理消息，聊天历史以明文保存。具有主机、数据库或备份访问权限的维护者可以读取相关记录。

## 账号安全

- **身份认证。** Java 版使用 Minecraft 正版认证；基岩版通过 Xbox / Microsoft 账号认证并关联 Java 账号。服务器另设附加密码验证。
- **密码保护。** 附加密码以加盐哈希形式存储，维护人员无法查询原密码。获授权的管理人员重置密码时可以看到生成的新密码。玩家收到后应尽快登录并自行修改。
- **网页登录。** 支持游戏内确认的临时验证码及 Passkey。Passkey 私钥保存在你的设备或密码管理器中，官网仅保存公钥及凭据标识，不接收指纹、人脸或设备 PIN。

你可以在[账号安全](/zh-CN/account/security)管理 Passkey 和网页会话。撤销 Passkey 不会自动注销已有会话。

**AI 助手。** 使用时，问题、对话上下文及查询结果会发送至模型服务，可能包含背包信息；启用位置查询时还可能包含游戏坐标。开启知识学习或个人记忆后，系统会保存从对话中提取的内容。`/ai clear` 仅清空当前对话，已保存的知识和记忆可联系维护者删除。

上述服务可能跨境处理数据，具体处理地区及传输保障可通过隐私联系渠道查询。

## 浏览器数据与保存期限

网页登录使用必要 Cookie，主题及通知偏好保存在浏览器中。

| 数据 | 保存或有效期限 |
| --- | --- |
| 角色存档、进度、统计及共享世界 | 按游戏运行和世界维护需要持续保存 |
| 聊天数据库历史记录 | 录入后通常保留 **7 天** |
| 网页会话 | **30 天未活动**或签发后 **90 天**失效，可主动注销 |
| 登录及绑定验证码 | 通常 **5 分钟** |
| 正版认证缓存 | 认证成功后 **72 小时**，仅在官方认证故障时用于相同 IP 的重连核验 |
| 投稿审核记录 | 审核完成后 **14 天**；公开作品及图床图片独立保存 |
| 浏览器聊天记录 | 默认不自动过期；可在聊天设置中清理或关闭并清空，退出登录或切换账号时清空 |
| 账号绑定关系 | 保留至解绑 |
| AI 知识与记忆 | 不自动过期，可申请删除 |

控制台日志、系统备份及第三方平台消息采用独立的保存机制，不随聊天数据库的历史记录同步删除。

## 未成年人隐私保护

依法需要监护人同意的个人信息处理，将事先说明并取得有效同意。

涉及未成年人的举报和申诉材料仅向必要的处理人员提供，公开结果时隐去隐私信息。

未成年人及其监护人可通过前述渠道提出隐私请求。我们会核验必要的身份及监护关系，并考虑未成年人的意愿和利益。

## 隐私请求与更新

你可以申请查阅、获取副本、更正、删除、限制处理、依法导出个人信息或撤回同意，也可以依法反对基于正当利益的处理。我们会核验申请人的身份，并按适用法律处理请求。

符合删除条件的信息将从正在使用的系统中删除或匿名化，但不必然涉及共享世界中的建筑、公共项目及他人作品。

历史备份可能无法立即清理。我们会说明清理方式及预计时间，在清理前限制相关数据的日常使用，并在备份恢复时执行适用的删除或匿名化措施。依法需要保留或处理未决争议所必需的信息，可能受到删除限制。

请求原则上免费，通常在收到后 **一个日历月内**答复；法律要求更短期限的从其规定。需要依法延长时，我们会及时告知原因及预计答复时间。你也可以向有管辖权的隐私监管机构投诉。

入服、晋升及治理资格由系统根据绑定、验证和游玩记录判断；QQ 消息转发经过内容审核。对自动处理结果有异议时，可以申请人工复核。

发生依法需要通知的个人信息安全事件时，我们会向受影响用户说明影响及补救措施。重要政策变更将提前公布，依法需要同意的将另行征求。
