## 适用与联系

Encinet 团队负责 Mik Casual 游戏服务器、官网，以及由团队控制的 QQ、Matrix 社区功能中相关个人信息的处理。第三方平台独立开展的数据处理，适用其各自的隐私政策。

隐私问题或数据请求，请在[社区](/zh-CN/join)私信维护者（Custodian）。涉及玩家数据时，请附玩家名或 UUID。

## 数据与用途

我们仅处理提供和维护服务、保障账号及社区安全，以及实现已说明功能所必需的个人信息。我们尽可能限制信息的收集、访问和保留范围，并说明信息的用途及你的相关权利。

| 范围 | 处理的数据与用途 |
| --- | --- |
| Minecraft 联机与存档 | IP、UUID、玩家名、皮肤及连接信息用于联机、身份核验与显示；位置、物品栏、末影箱、进度与统计用于保存和恢复角色状态；方块、建筑、容器、实体、告示牌和书本等随世界保存 |
| 本服功能 | QQ／Matrix 账号标识、成员资格和绑定关系用于入服核验；权限、地段、设置与游玩记录用于访问控制、建筑保护、偏好保存和晋升；治理、操作记录及举报证据用于社区投票、规则执行和纠纷处理 |
| 官网功能 | IP、请求、浏览器及错误记录用于提供页面和防护；临时登录验证、Passkey 公钥与会话信息用于网页登录；投稿者身份、作品说明、坐标、图片与审核记录用于建筑收录 |

数据来自你的连接、游戏与网页操作、提交内容，以及游戏认证和社区平台。入服须保留至少一条有效的 QQ 或 Matrix 绑定。

我们不出售个人信息。为提供你请求的游戏、账号及社区功能，我们基于履行服务约定处理必要信息；依法必须保存或披露信息时，以履行法定义务为依据。在适用法律允许以正当利益为依据时，我们为保护账号、作品与服务安全，处理安全防护、违规处置及申诉所需的信息。依法需要取得同意的，我们会事先说明并征求同意。

## 通信与公开范围

- **公共聊天**在游戏、网页和 Matrix 间同步，并写入控制台日志。QQ 一群的消息会同步至这些公共频道；发往 QQ 的公共消息须以半角 `#` 开头并通过审核，详见[互通规则](?section=chat#平台互通)。
- **私聊**向双方投递，**管理频道**按权限投递，均不转发到 QQ 群或 Matrix 房间。
- **语音聊天**由 Plasmo Voice 处理并传给收听者。
- 官网与公开接口提供玩家名、UUID、皮肤、在线状态和本次入服时间，无需登录即可查看；建筑坐标、图片、署名及公开处分和治理结果按[服务器规则](?section=rules)展示。

网页聊天采用浏览器与游戏服务端之间的应用层加密，消息正文在进入 Cloudflare 代理前加密。Cloudflare 可见 IP 地址、连接时间等网络信息，但不持有聊天正文的应用层解密密钥。

游戏服务端解密处理消息，并以明文保存聊天历史；有主机、数据库或备份访问权限的维护者能够读取这些记录。

## 账号安全

- **身份认证。** Java 版使用 Minecraft 正版认证；基岩版通过 Xbox / Microsoft 账号认证，并关联 Java 账号。服务器另设附加密码验证，用于增强账号安全。

- **密码保护。** 附加密码以加盐哈希形式存储，维护人员无法查询原有密码。获授权的管理人员可以重置附加密码，重置生成的新密码会向执行者显示。为保护账号安全，玩家应在收到重置密码并成功登录后立即自行修改。附加密码不替代游戏账号认证。

- **网页登录。** 官网支持通过游戏内确认的临时验证码或 Passkey 登录。Passkey 私钥由你的设备或密码管理器保管；官网保存公钥及凭据标识，不接收指纹、人脸或设备 PIN。

你可在[账号安全](/zh-CN/account/security)管理 Passkey 和网页会话。**撤销 Passkey 不会自动注销已有会话。**

使用 AI 助手时，你的问题、对话上下文和查询结果会发送给模型服务，可能包含你的背包；服务器启用位置查询时，还可能包含游戏坐标。启用知识学习或个人记忆后，会保存从对话中提取的内容；`/ai clear` 只清空当前对话，已保存的知识和记忆可联系维护者申请删除。

这些服务可能跨境处理数据；可通过隐私联系渠道查询处理地区及传输保障。

## 浏览器数据与保存期限

网页登录使用必要 Cookie，主题与通知偏好保存在浏览器。

| 数据 | 保存或有效期限 |
| --- | --- |
| 角色存档、原版进度与统计、共享世界 | 按游戏运行与世界维护需要持续保存 |
| 聊天数据库历史记录（公共、管理和私聊） | 通常在录入 **7 天**后清理 |
| 网页会话 | **30 天未活动**或签发后 **90 天**失效，可主动注销 |
| 临时登录验证、绑定验证码 | 通常 **5 分钟**有效 |
| 正版认证缓存 | 官方认证成功后 **72 小时**有效，仅在官方认证故障时用于相同 IP 的重连核验 |
| 投稿审核记录 | 审核完成后 **14 天**；公开建筑和图床图片独立保存 |
| 浏览器聊天记录 | 默认无自动到期时间；可在聊天设置中清理或关闭并清空，退出登录或切换账号时清空 |
| 账号绑定关系 | 保留至解绑 |
| AI 提取的知识与记忆 | 无自动到期时间；可联系维护者申请删除 |

控制台日志、系统备份及已同步至第三方平台的消息各有独立的保存机制；清理聊天数据库中的历史记录，不代表这些副本同步删除。

## 未成年人隐私保护

依法需要监护人同意的个人信息处理，以事先向监护人说明处理内容并取得有效同意为前提。

涉及未成年人的举报、申诉证据仅向必要的处理人员提供，公开处理结果时隐去其中的隐私信息。

未成年人可自行提出隐私请求，监护人也可依法代为提出。请通过[社区](/zh-CN/join)私信维护者；我们会核验请求人的身份及必要的监护关系，并考虑未成年人的意愿和利益。

## 隐私请求与更新

你可通过上述联系方式申请查阅、获取副本、更正、删除、限制处理、依法导出数据或撤回同意。**你也可依法反对基于正当利益的处理。**

处理数据请求时，我们会核验你的身份。

对于符合删除条件的个人信息，我们会从正在使用的系统中删除或作匿名化处理。个人信息删除请求不必然导致共享世界中的建筑、公共项目及其他参与者的作品被删除。

历史备份中的相关信息可能无法立即清除；我们会说明清理方式及预计完成时间，并在清理前停止使用这些信息。从历史备份恢复系统时，会在相关数据重新投入使用前执行适用的删除或匿名化措施。

依法需要保留，或为处理未决争议确有必要且依法可以保留的信息，可能受到删除限制。我们会说明保留的范围和理由。

请求原则上免费。我们通常在收到请求后 **一个日历月内**答复；适用法律要求更早答复的，按其规定。依法延长时，会在原期限内说明原因和预计答复时间。你也可向有管辖权的数据保护或隐私监管机构投诉。

入服、晋升与治理资格根据绑定、验证和游玩记录自动判断，QQ 转发按内容审核结果处理。对结果有异议，可联系维护者申请人工复核。

发生个人信息安全事件时，我们会依法通知受影响的用户，说明影响和补救措施。重要政策变更会提前公布；依法需要同意的会另行征求。
