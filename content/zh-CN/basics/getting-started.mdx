Mik 是以建筑创作和交流为主的创造休闲服。

## 入服前准备

<Definitions>
<Definition title="Java 版">

服务器版本 `26.3`，支持正式版 `1.21.10 ~ 26.3`。

</Definition>
<Definition title="基岩版">

支持最新几个正式版。入服前完成 [Geyser 账号绑定](https://link.geysermc.org/start)。

</Definition>
</Definitions>

## 如何加入服务器

<Steps>
<Step title="加入社区">

[服务器规则](?section=rules) · [加入 QQ 或 Matrix](/zh-CN/join)

- **QQ**：在加入页面获取入群码，完成验证后加入群聊
- **Matrix**：通过加入页面加入社区空间，再加入其中有机器人的聊天房间

</Step>
<Step title="连接服务器，获取绑定指令">

Java 版地址：

```text
mcmik.top
```

基岩版地址与端口请在社区内查询。

尚未绑定时，断开界面会提供各平台的完整绑定指令。选择一个平台，复制对应指令；六位数字验证码 5 分钟内有效。

</Step>
<Step title="完成绑定后重新连接">

- **QQ**：在接入群中 @机器人，发送界面中的 `/bind <验证码>`
- **Matrix**：在接入的聊天房间发送界面中的 `!bind <验证码>`

任意一个平台绑定成功后，重新连接服务器即可。QQ 的六位入群码只用于加群，与游戏账号绑定验证码不同。

</Step>
</Steps>

入服需至少一条有效的平台绑定，账号需留在接入社区。Matrix 以社区空间（Space）的成员资格为准，聊天房间用于发送指令。

## 首次进入服务器

首次进入会到达主城。

<Definitions>
<Definition title="主菜单">

潜行时按副手切换键（默认 `Shift + F`）打开，也可用 `/menu`。

</Definition>
<Definition title="/spawn" code>

回到主城。

</Definition>
<Definition title="/home" code>

查看已保存的家。

</Definition>
</Definitions>

<Callout title="新人权限">

新人可建造和交流；大范围编辑等高影响操作需成为成员。晋升条件见[新人与成员](?section=rules#新人与成员)。

</Callout>

离开游戏后也能使用[网页聊天](/zh-CN/chat)，频道、私聊和平台互通见[聊天系统](?section=chat)

## 开始创作

<Steps>
<Step title="选址">

[世界地图](/zh-CN/map) · [地段与建设规则](?section=rules#地段与建设)

</Step>
<Step title="保存位置">

```mcfunction
/sethome base
```

保存当前位置为 `base`，用 `/home base` 返回。

</Step>
</Steps>

成员可在主菜单登记地段。

<Callout kind="warning" title="世界边界">

主世界边界直径 `9126` 格，玩家、建筑和实体不得越界。

</Callout>

Java 版可选模组。

<Definition title="语音与音乐">

[Plasmo Voice](https://modrinth.com/plugin/plasmo-voice)：语音聊天和服务器音频播放。

</Definitions>

## 遇到问题

<Details title="提示需要绑定，或绑定后仍无法进入">

按断开界面显示的指令，在已接入的 QQ 群或 Matrix 房间完成绑定，然后重新连接。验证码过期时重新连接获取；提示成员资格暂时无法核验时，稍后重试或联系管理。仍无法进入时，提供 Java 用户名和完整报错；基岩版同时提供关联的 Java 账号。

</Details>

<Details title="退群或退出 Matrix 空间后还能入服吗">

同一账号仍在该平台的其他接入社区时，绑定会保留。系统确认已离开该平台的全部接入社区后，会解除对应绑定，其他有效绑定不受影响。全部绑定失效后无法入服，需重新加入社区并完成绑定。

</Details>

<Details title="提示版本不兼容，或基岩版绑定后无法连接">

检查游戏版本；基岩版还需检查 Geyser 账号关联、社区平台绑定、地址和端口。求助时附上游戏版本和完整报错。

</Details>

<Details title="能入服，但某些工具或指令不能用">

部分功能需要成员身份或额外权限。在主菜单查看身份，指令用法见[常用指令](?section=commands)。

</Details>
