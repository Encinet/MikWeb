Mik 是以建筑创作和交流为主的创造休闲服。

## 入服前准备

<Definitions>
<Definition title="Java 版">

服务器版本 `26.3`，支持正式版 `1.21.10 ~ 26.3`。

</Definition>
<Definition title="基岩版">

支持最新几个正式版。入服前完成 [Geyser 账号绑定](https://link.geysermc.org/start)。

</Definition>
</Definitions>

## 如何加入服务器

<Steps>
<Step title="申请白名单">

[服务器规则](?section=rules) · [申请入口](/zh-CN/join)

- **QQ 群申请**：加入 QQ 群，按群公告申请；结果在群内通知
- **表单申请**：提交表单，填写 Java 用户名、邮箱和简短自我介绍；结果通过邮件通知

</Step>
<Step title="连接服务器">

Java 版地址：

```text
mcmik.top
```

基岩版地址与端口见申请渠道。

</Step>
</Steps>

## 首次进入服务器

首次进入会到达主城。

<Definitions>
<Definition title="主菜单">

潜行时按副手切换键（默认 `Shift + F`）打开，也可用 `/menu`。

</Definition>
<Definition title="/spawn" code>

回到主城。

</Definition>
<Definition title="/home" code>

查看已保存的家。

</Definition>
</Definitions>

<Callout title="新人权限">

新人可建造和交流；大范围编辑等高影响操作需成为成员。晋升条件见[新人与成员](?section=rules#新人与成员)。

</Callout>

## 开始创作

<Steps>
<Step title="选址">

[世界地图](/zh-CN/map) · [地段与建设规则](?section=rules#地段与建设)

</Step>
<Step title="保存位置">

```mcfunction
/sethome base
```

保存当前位置为 `base`，用 `/home base` 返回。

</Step>
</Steps>

成员可在主菜单登记地段。

<Callout kind="warning" title="世界边界">

主世界边界直径 `6144` 格，玩家、建筑和实体不得越界。

</Callout>

## 推荐模组

Java 版可选模组。

<Definitions>
<Definition title="语音与音乐">

[Plasmo Voice](https://modrinth.com/plugin/plasmo-voice)：语音聊天和服务器音频播放。

</Definition>
<Definition title="探索与定位">

[Xaero's World Map](https://modrinth.com/mod/xaeros-world-map)：已探索区域地图。[Xaero's Minimap](https://modrinth.com/mod/xaeros-minimap)：小地图。

</Definition>
<Definition title="建筑编辑">

[Axiom](https://modrinth.com/mod/axiom)：建筑和地形编辑。WorldEdit 由服务端提供，无需客户端模组。

</Definition>
</Definitions>

<Details title="优化整合包与其他客户端工具">

- [Fabulously Optimized](https://modrinth.com/modpack/fabulously-optimized) / [Rapid Optimization](https://modrinth.com/modpack/rapid_optimization)：优化整合包。
- [ImageFrame Client](https://modrinth.com/mod/imageframeclient)：地图画高清与彩色显示，受服务端和图片类型限制。
- [Vivecraft](https://modrinth.com/mod/vivecraft)：VR 游玩。
- [Hey Wiki](https://modrinth.com/mod/hey-wiki)：游戏内查询 Wiki。
- [Distant Horizons](https://modrinth.com/mod/distanthorizons) / [voxy](https://modrinth.com/mod/voxy)：远景渲染。

</Details>

## 遇到问题

<Details title="提示不在白名单，或申请后仍无法进入">

在 QQ 群或邮件中查看审核结果。仍无法进入时，向管理提供 Java 用户名和完整报错；基岩版同时提供关联的 Java 账号。

</Details>

<Details title="提示版本不兼容，或基岩版绑定后无法连接">

检查游戏版本；基岩版还需检查账号绑定、白名单、地址和端口。求助时附上游戏版本和完整报错。

</Details>

<Details title="能入服，但某些工具或指令不能用">

部分功能需要成员身份或额外权限。在主菜单查看身份，指令用法见[常用指令](?section=commands)。

</Details>
